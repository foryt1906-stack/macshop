# Моя крамниця

Настільна програма для Facebook-магазину з віконним інтерфейсом у стилі початкового макета.
Це не вкладка браузера й не сторінка Excel.

## Запуск

Двічі клацни `dist\MoiaKramnytsia.exe` або `Запустити програму.bat`.
EXE запускається окремим вікном без адресного рядка браузера та без встановлення Python.

## Дані

База даних зберігається на цьому комп’ютері в:

Windows: `%LOCALAPPDATA%\MoiaKramnytsia\shop.sqlite3`

macOS: `~/Library/Application Support/MoiaKramnytsia/shop.sqlite3`

Браузерна сторінка `index.html` і Windows-програма мають окремі сховища даних.
Для роботи з базою програми запускай `dist\MoiaKramnytsia.exe`.

Для захисту даних регулярно натискай **«Резервна копія»** у програмі.
У вкладці **«Звіти й зміна»** також є резервне копіювання та відкриття папки з базою.

Замовлення й повідомлення для клієнтів можна вести у програмі та вручну надсилати через Facebook Messenger.
Інтернет-з’єднання не потрібне, програма не надсилає записи в інтернет.

## Поширення програми

Сторінка `share\index.html` має кнопки для Windows, Mac на Apple Silicon та Mac
на Intel. Кнопки ведуть на останні файли GitHub Releases. GitHub Actions збирає
версії для цих платформ після додавання файлів проєкту в репозиторій і публікації
тега на кшталт `v1.0.0`. Не публікуй локальну базу даних або резервні копії.

EXE поки не підписаний довіреним сертифікатом видавця. Для довіреного підпису
потрібен сертифікат від центру сертифікації; самопідписаний сертифікат не
прибере попередження Windows на чужих комп’ютерах. SHA-256 опублікований
у `share\SHA256SUMS.txt`.

Mac-застосунок також не підписаний Apple Developer ID і не нотаризований,
тому macOS може показати попередження Gatekeeper під час першого запуску.
