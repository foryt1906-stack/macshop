Приватність — на твоєму боці

Програма не підключається до Facebook та не надсилає записи в інтернет. Кожен користувач має окремі дані на своєму комп’ютері. Щоб перенести записи, створи й передай резервну копію окремо.

Примітка Windows: програма ще не підписана сертифікатом видавця. Windows може показати попередження під час першого запуску. Перед завантаженням перевіряй, що отримав файл із довіреного джерела. Не вимикай захист Windows для встановлення.

Примітка macOS: програма ще не підписана Apple Developer ID і не нотаризована. Під час першого запуску macOS може показати попередження Gatekeeper.

Кнопки завантажують останні файли з GitHub Releases. Файли з’являться після завантаження проєкту в GitHub і першої успішної збірки.
